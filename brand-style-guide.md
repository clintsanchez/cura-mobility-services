## Logo Guidelines

**Versions on file (`01-Brand-Assets/`):** _list as assets land._

**Recommended official versions to produce:**
- Full-color (primary)
- On-dark
- On-light
- Mark-only (favicon / avatar)

**Clear space:** equal to the height of one key element of the mark, all sides.
**Minimum size:** 160px wide (full lockup) / 32px (mark-only favicon) digital.

## Color Palette

> Client gave no color names. Hex sampled from the survey logo JPG (raster); confirm against vector files when received. Token names match
> `css-tokens.css` and `DESIGN.md`.

| Token | Hex | Use |
|---|---|---|
| `--brand-primary`   | `#02265A` | Primary: logo navy (14.7:1 on white) |
| `--brand-secondary` | `#058D8D` | Logo teal: large type and graphics only (4.04:1 fails AA body) |
| `--brand-accent`    | `#047878` | Text-safe teal for links and buttons (5.3:1) |
| `--bg-base`         | `#FFFFFF` | Page background |
| `--bg-surface`      | `#F3F6F9` | Card / surface |
| `--text-primary`    | `#1A2433` | Body text |
| `--text-muted`      | `#5A6675` | Secondary text |

**Contrast rule:** verify every text/background pair hits WCAG AA (4.5:1 body).
